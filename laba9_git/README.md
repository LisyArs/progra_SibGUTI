### 11. Почему так происходит?
сейчас в git есть три разных состояния файла. 1. Старая версия без main() в коммите; 2. Версия с массивом {4, 2, 0} в staged; 3. Версия с массивом {4, 0} в рабочем каталоге. Команда git diff сравнивает рабочий файл с индексом, а git diff --staged сравнивает индекс с послденим коммитом.
